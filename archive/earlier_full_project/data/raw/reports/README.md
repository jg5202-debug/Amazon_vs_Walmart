# Official Report References

The supplied raw CSV files are verified manual transcriptions of the selected official annual-report tables, not an automated scraper output. Full HTML reports are not bundled. Direct SEC downloads returned HTTP 403 in this environment; the figures were verified through web access. No HTML snapshot is claimed to have been saved.

Open the official links in source_manifest.json or source_notes.md to review the tables. Optional local copies may be saved here as amazon_2021_10k.html, amazon_2024_10k.html, walmart_fy2022_10k.html and walmart_fy2025_10k.html. Running Module 02 uses the supplied CSV files and does not require a network request or local HTML snapshots.

Do not replace the raw files with invented data or consolidated totals. For a different study, transcribe its own reported segment figures and record the report version, table location, currency, unit and period dates.
